# sTools releases

Release downloads and the update feed for sTools.

- **Download:** the newest DMG is under [Releases](https://github.com/ducky8x/sTools-releases/releases).
- **Updates:** sTools checks `appcast.xml` in this repository once a day (Settings ▸ Updates) and offers each new version. Every download is signed with sTools' update key and with the same "ducky8x" certificate.

sTools isn't notarized, so macOS blocks it the first time. Open it once, then go to **System Settings ▸ Privacy & Security** and click **Open Anyway**.

This repository holds only releases; the source code is private.
